- 명령어: 로드 밸런싱 상태를 점검하는 명령어.
- Cisco SAN 장비에는 L4/L7 로드밸런서의 serverfarm, real server, health-check 구조를 사용하지 않으므로 점검 대상이 아님.

- **양호**: 점검 대상이 아님.
- **경고**: 점검 대상이 아님.
- **확인 필요**: 점검 대상이 아님.

            message='점검 대상이 아닙니다.',
