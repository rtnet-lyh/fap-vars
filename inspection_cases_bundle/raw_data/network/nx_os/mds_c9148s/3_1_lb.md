# 영역
서비스

# 세부 점검항목
각 LB상태 확인

# 점검 내용
부하 분산 상태 점검 및 real 서버 health-check 상태 점검

# 구분
권고

# 명령어
```bash
show serverfarm
```

# 출력 결과
```text
CITS-SAN1# show serverfarm
                 ^
% Invalid command at '^' marker.


```

# 설명
- 명령어: 로드 밸런싱 상태를 점검하는 명령어.
- Cisco SAN 장비에는 L4/L7 로드밸런서의 serverfarm, real server, health-check 구조를 사용하지 않으므로 점검 대상이 아님.
